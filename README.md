# Entry Info Bot — Entry Story Scheduler v2.0.2

**Chrome / Edge 확장프로그램 (Manifest V3)**입니다. 엔트리 이야기 목록 페이지에서 로그인한 계정의 **최근 게시글**을 확인하고, 해당 글에 사전에 입력한 문구를 일정 간격으로 댓글로 작성할 수 있습니다. **새 글**은 조건을 검사해 **초안만 준비**합니다. 검토·복사 후 사용자가 직접 게시해야 합니다.

> 기존 정보 조회용 콘솔 봇은 별도의 [console.js](./console.js)에 그대로 보관합니다. v2 설치 시 과거 콘솔 봇은 자동 실행되지 않습니다.

## 설치

1. GitHub 저장소 상단 **Code → Download ZIP**을 누르고 압축을 풉니다.
2. Chrome에서 \`chrome://extensions\`, Edge에서 \`edge://extensions\`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 누릅니다.
4. 압축을 푼 \`Entry_Info_Bot-main\` 폴더(그 안에 \`manifest.json\`이 있는 곳)를 선택합니다.
5. \`https://playentry.org/community/entrystory/list?sort=created&term=all\`에서 엔트리에 로그인합니다.
6. 브라우저 도구 모음의 확장프로그램 아이콘을 눌러 댓글/새 글 문구와 조건을 지정한 뒤 **설정 저장 → 미리보기 → 자동 확인 시작**을 선택합니다.

자동 확인은 브라우저와 엔트리 이야기 탭이 열려 있을 때만 동작하며, 24시간 독립 실행되는 서버 봇이 아닙니다. 확장프로그램을 업데이트했다면 엔트리 이야기 탭을 새로고침하세요.


## 로그인/연결 오류 해결 (v2.0.2)

- **엔트리 로그인 세션 확인 실패**: v2.0.2는 계정 정보의 `_id` 및 `id` 형식을 모두 지원합니다. 현재 페이지에 토큰이 없을 때는 **로그인된 동일 엔트리 사이트의 홈 화면**을 읽어서 세션을 다시 확인합니다. 계정 비밀번호를 입력하거나 외부 서버에 토큰을 전송하지 않습니다.
- **Could not establish connection / Receiving end does not exist**: 이미 열어 둔 탭에 콘텐츠 스크립트가 없는 경우 자동으로 한 번 재연결합니다.
- 기존 설치에서 오류가 계속되면 `chrome://extensions` 또는 `edge://extensions`에서 확장프로그램을 새로고침하고, **엔트리이야기 탭도 새로고침**한 후 팝업의 **미리보기**를 다시 누르세요.
- 로그인은 확장프로그램을 설치한 **같은 브라우저 프로필**의 `https://playentry.org/`에서 해야 합니다.
- 여전히 로그인 정보가 없다는 오류가 표시되면 오류 메시지에서 **어떤 항목(계정 ID, xToken, CSRF 토큰)**을 읽지 못했는지 확인하세요. **실제 토큰, 쿠키, 비밀번호는 공유하지 마세요.**
- 실제 로그인 세션에서 인증 및 댓글 발행을 최종 검증한 상태는 아닙니다. 엔트리 사이트 변경 시 API 호환성 수정이 필요할 수 있습니다.

## 기능

| 설정 | 동작 |
| --- | --- |
| 댓글 문구 목록 | 한 줄에 하나씩 최대 50개, 각 문구 최대 500자 |
| 순서대로 | 문구 1 → 2 → 3 → 1 순으로 반복 |
| 랜덤 | 가능한 경우 직전 문구와 중복되지 않도록 선택 |
| 댓글 간격 | 최소 15분, 최대 24시간 |
| 댓글 일일 한도 | 최근 24시간에 1~6회 (기본 4회) |
| 댓글 대상 | 최근 엔트리 이야기 100개 글 중 **내 계정의 최신 글 한 개** |
| 새 글 문구 | 댓글과 별도로 관리하는 문구 목록 |
| 새 글 모드: 글 수 | 내 글보다 최근에 등록된 새 글이 N개 이상 |
| 새 글 모드: 경과 시간 | 내 글 작성 후 N분 이상 |
| 새 글 모드: 둘 다 | 글 수 기준과 시간 기준을 동시에 만족 |
| 새 글 처리 | 자동 게시 대신 초안을 저장하고 팝업에서 직접 복사 |
| 미리보기 | 댓글 발행 없이 조건과 다음 문구만 확인 |
| 중지 | 알람 확인 및 이후 발행 중지 |

안전 및 제약: 로그인한 **현재 계정** 외의 글에는 댓글을 달지 않습니다. 한 번의 확인에서 댓글을 최대 한 개만 발행합니다. 댓글 요청이 성공했는지 불분명한 경우 중복 게시를 막기 위해 자동 재시도하지 않습니다. 인증 오류·HTTP 429·CAPTCHA·도배 제한이 감지되면 실행을 중단하며 이를 우회하지 않습니다. 댓글 시각·문구 순번과 새 글 초안은 같은 브라우저의 로컬 저장소에만 보관하고 인증 토큰을 저장하지 않습니다.

**중요한 구현 상태:** 실제 사이트에 로그인한 브라우저에서 최종 동작 검증은 하지 못했습니다. 엔트리의 비공식 GraphQL 스키마가 변경되면 댓글 기능이 실패할 수 있습니다. 새 글의 자동 발행 API는 검증되지 않아 구현하지 않았습니다. '새 글' 조건은 최대 최근 100개 글에서 내 글을 찾을 수 있을 때만 평가합니다.
