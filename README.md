# Entry Info Bot

엔트리 이야기에서 `!'닉네임'정보` 형식의 새 글을 감지하고, 사용자의 작품·팔로워·팔로잉·인기작품(인작)·스태프 선정(스선) 수를 조회하는 Chrome/Edge 확장 프로그램입니다.

> **개발/실험용**: 비공식 엔트리 GraphQL API를 사용합니다. 실제 브라우저에서의 동작은 사이트 변경과 운영 정책에 영향을 받을 수 있습니다. 자동 댓글 작성은 **기본적으로 꺼져 있으며, 실행 시 사용자가 확인해야 합니다**.

## 설치
1. 이 저장소의 코드를 ZIP으로 내려받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**에서 해당 폴더를 선택합니다.
4. 엔트리에 로그인하고 `https://playentry.org/community/entrystory/list?sort=created&term=all`을 엽니다.
5. 확장 프로그램 아이콘에서 **닉네임 조회 테스트**로 조회 기능을 확인합니다(테스트는 댓글을 작성하지 않습니다).
6. **자동 댓글 봇 실행** 스위치를 켜고 안내를 확인합니다.
7. 이제 **다른 사람이** `!'12옴'정보` 형식의 새 게시글을 올리면, 봇 계정이 **그 게시글에 댓글**을 자동 작성합니다.
8. 봇을 멈추려면 스위치를 끕니다.

## 명령어 및 결과
- 입력: `!'12옴'정보`
- 유효한 닉네임이 조회되면 작품 수, 팔로워 수, 팔로잉 수, 인작 수, 스선 수를 댓글로 작성합니다.
- 정확히 일치하는 유저가 없으면: `그런 유저 없음`
- 서버 오류·로그인 오류·집계 불완전은 사용자 없음으로 처리하지 않습니다.

## 작동 방식
- 새로운 엔트리 이야기 게시글만 약 30초 간격으로 확인합니다. 봇 시작 이전 글은 무시합니다.
- **다른 사람의 명령어 게시글 ID를 댓글 대상(target)으로 설정**합니다. 별도 게시글을 올리는 것이 아닙니다.
- Chrome 확장 프로그램 서비스 워커가 주기적으로 감지 신호를 보내므로 엔트리 이야기 탭이 뒤에 있어도 작동할 수 있습니다.
- 브라우저가 실행 중이고 엔트리 이야기 탭이 열려 있어야 합니다. 컴퓨터/브라우저가 꺼지면 동작하지 않는 **확장 프로그램 방식**입니다.
- 공개된 [ent2-backup](https://github.com/entrykinetictypo/ent2-backup)의 닉네임 검색, 프로필 조회, 작품 조회 패턴을 참고해 엔트리 GraphQL API에 직접 조회합니다.
- 별도 로그인 비밀번호나 토큰을 저장하지 않고, 로그인한 엔트리 페이지의 세션을 사용합니다.
- 중복 댓글 시도를 방지하며, 댓글 사이에 최소 60초 간격, 시간당 최대 10회 제한을 둡니다. 제한에 걸리면 명령어를 최대 40건까지 대기열에 보관합니다.
- HTTP 429 등 제한 응답이 발생하면 자동 댓글을 끕니다. CAPTCHA나 접근 제한을 우회하지 않습니다.
- 같은 닉네임을 조회할 때 **정확한 일치**만 인정합니다.
- 최대 2,500개 작품까지 페이지를 순회하여 인작/스선을 셉니다. 완전히 확인하지 못하면 집계 실패로 표시합니다.

## 파일 구성
- `manifest.json`: Manifest V3 설정
- `src/core.js`: 명령어 파서·응답 메시지 구성
- `src/content.js`: 엔트리 API 조회·새 글 감지·원본 게시글에 댓글 작성
- `src/background.js`: 비활성 탭에도 주기적인 조회 신호 전송
- `src/popup.js`: 설정 및 수동 조회 테스트
- `popup.html`, `popup.css`: 설정 화면
- `tests/core.test.js`: 순수 로직 단위 테스트

## 개발 테스트
```sh
node --test tests/core.test.js
```

## 주의
이 프로그램은 엔트리 공식 제품이 아니며 Chrome 웹 스토어 심사를 통과했다는 뜻도 아닙니다. 엔트리의 자동화·댓글 작성 정책을 확인하고, 과도한 요청이나 반복성 댓글을 삼가 주세요. 비밀번호나 개인 토큰을 소스 코드·저장소에 넣지 마세요.
