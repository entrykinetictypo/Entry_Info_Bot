# Entry Info Bot — Console edition

엔트리 이야기에서 **본인 또는 다른 사람**이 다음 명령어를 *새 게시글 본문*에 작성하면, 현재 로그인한 봇 계정이 **그 게시글에 댓글**로 정보를 자동 작성하는 JavaScript 봇입니다.

```text
!'12옴'정보
```

> 브라우저 개발자도구 콘솔 실행 방식입니다. Chrome 확장 프로그램을 설치할 필요가 없습니다. 비공식 엔트리 GraphQL API를 사용하므로 실제 사이트 업데이트에 따라 동작하지 않을 수 있습니다.

## 실행 방법

1. 댓글을 달 **봇 계정**으로 엔트리에 로그인합니다.
2. 엔트리 이야기 목록 페이지 `https://playentry.org/community/entrystory/list?sort=created&term=all`에 접속합니다.
3. 이 저장소의 **[`console.js`](./console.js)**를 열고 전체 코드(Ctrl+A, Ctrl+C)를 복사합니다.
4. 엔트리 이야기에서 **F12 → Console**을 열어 코드를 붙여넣고 Enter를 누릅니다. 신뢰하는 코드인지 먼저 검토해 주세요.
5. 자동 댓글 실행을 확인하는 대화상자에서 **확인**을 누릅니다.
6. 봇 실행 이후 **본인 또는 다른 사람**이 `!'닉네임'정보` 글을 새로 작성하면, 봇이 해당 글에 댓글을 남깁니다.
7. **이미 올려둔 내 테스트 글**에도 댓글을 달고 싶다면 `await EntryInfoBot.replyToOwnPost("삼류")`를 실행합니다. 최근 게시글 20개에서 *내 계정*의 정확한 명령어를 찾아 **그 글에만** 댓글을 작성합니다.

코드는 외부 서버에서 추가 스크립트를 내려받아 실행하지 않습니다. 비밀번호를 입력받거나 인증 토큰을 GitHub 또는 저장소에 전송하지 않습니다. 로그인한 엔트리 페이지의 세션만 이용합니다.

## 명령어와 댓글

명령어는 다음처럼 **ASCII 작은따옴표로 닉네임을 감싸야** 합니다.

- `!'12옴'정보` → 해당 닉네임의 작품 수, 팔로워, 팔로잉, 인기작품(인작), 스태프 선정(스선) 수
- `!'없는닉네임'정보` → 닉네임이 실제로 없다는 것을 API로 확인한 경우에만 `그런 유저 없음`
- `!12옴정보` → 무시 (형식이 다름)

댓글 예시:

```text
📊 12옴님의 정보
작품 수: [실제 조회한 수치]개
팔로워 수: [실제 조회한 수치]명
팔로잉 수: [실제 조회한 수치]명
인작 수: [실제 조회한 수치]개
스선 수: [실제 조회한 수치]개
```

## 콘솔 명령어

```js
EntryInfoBot.start()                // 자동 댓글 시작
EntryInfoBot.preview()              // 댓글을 작성하지 않는 미리보기 모드
EntryInfoBot.status()               // 현재 상태 및 대기열 확인
EntryInfoBot.stop()                 // 즉시 자동 댓글 중지
await EntryInfoBot.replyToOwnPost("삼류")  // 이미 올린 내 글에 댓글 달기(최근 20개 내에서)
await EntryInfoBot.test("12옴")    // 실제 API로 유저 정보 조회 테스트, 댓글 작성 없음
EntryInfoBot.help()                 // 사용 가능한 명령어 안내
```

브라우저에서 코드를 다시 붙여넣으면 기존 타이머를 종료하고 다시 실행할 수 있습니다.

## 동작과 안전장치

- 시작할 때 이미 올라와 있는 글은 건너뜁니다. **그 이후 작성된 명령어 글**만 감지합니다.
- 매 30초 정도 최근 엔트리 이야기 목록을 조회합니다. 브라우저의 백그라운드 탭은 요청이 지연될 수 있습니다.
- 글 작성자가 봇 계정이어도 명령어가 정확하면 응답합니다. 단, 댓글을 감지 대상으로 사용하지 않으므로 자기 댓글에 연쇄 응답하지 않습니다.
- 실행 전 올린 테스트 글에는 자동 댓글을 달지 않습니다. `replyToOwnPost("삼류")` 명령어로 최근 내 글 하나를 명시적으로 지정할 수 있습니다.
- 새 게시글 ID를 댓글의 `target`으로 사용하고, `targetSubject: "discuss"`로 댓글을 작성합니다. 새로운 게시글을 따로 올리는 방식이 아닙니다.
- 60초당 최대 1회, 1시간당 최대 10회 댓글을 시도합니다. 대기열은 최대 40건입니다.
- 댓글 발행 성공 여부가 불확실한 경우 중복 댓글을 피하기 위해 자동 재시도하지 않습니다.
- 처리한 글 ID와 댓글 시도 시각만 같은 브라우저의 `localStorage`에 저장해 중복 응답을 방지합니다.
- HTTP 401/403/429 또는 CAPTCHA/도배 방지 응답을 받으면 중지하고 제한을 우회하지 않습니다.
- 닉네임을 정확히 비교하며, 조회 오류를 `그런 유저 없음`으로 오판하지 않습니다.
- 인작/스선 수는 조회 가능한 작품 목록을 최대 2,500개까지 순회해서 계산합니다. 조회가 불완전하면 댓글을 남기지 않습니다.

**중요:** 개발자도구 콘솔 방식이므로 페이지를 새로고침하거나 탭·브라우저를 닫으면 봇이 중단됩니다. 24시간 상시 운영되는 서버 봇은 아닙니다. 기존 확장 프로그램 구현은 Git 커밋 이력에 남아 있으며, 이 저장소의 현재 버전은 콘솔 방식입니다.

## 개발 및 테스트

Node.js v22 이상에서:

```sh
node --check console.js
node --test tests/*.test.js
```

GitHub Actions에서도 커밋마다 문법 검사와 모의 GraphQL 응답 테스트를 실행합니다.

이 도구는 엔트리 공식 서비스가 아닙니다. 엔트리의 운영 정책과 자동 댓글 허용 여부를 확인한 뒤 사용하세요.
