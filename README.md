# Entry Info Bot — 엔트리이야기 자동 관리 v2.2.2

Chrome / Edge용 Manifest V3 확장프로그램입니다. 로그인한 **본인의 글을 제외한 다른 사람의 최근 엔트리이야기 글**에 미리 지정한 댓글을 일정 시간 간격으로 쓰며, 설정한 **글 수 / 시간 / 두 조건 모두**가 충족되면 새 엔트리이야기 글을 선택적으로 자동 게시할 수 있습니다.

> 비공식 프로그램입니다. 엔트리 운영 정책에 맞게 사용하세요. 공개 글이나 댓글을 과도하게 반복하지 않도록 제한을 적용했습니다.

## 설치와 업데이트

1. 이 저장소의 **Code → Download ZIP**을 눌러 압축을 풉니다.
2. Chrome 주소창에 **chrome://extensions**, Edge에서는 **edge://extensions**를 입력합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 manifest.json이 있는 폴더를 선택합니다.
4. 기존 버전에서 교체한 경우 확장프로그램 카드의 **↻ 새로고침**을 누르고, **엔트리이야기 탭도 F5 새로고침**합니다.
5. 같은 브라우저에서 엔트리에 로그인하고 https://playentry.org/community/entrystory/list?sort=created&term=all 을 엽니다.
6. 확장프로그램 팝업에서 문구와 기준을 설정한 뒤 **설정 저장 → 조건 진단 / 미리보기 → 자동 확인 시작** 순으로 진행합니다.

탭과 브라우저가 열려 있어야 작동합니다. 서버에서 실행되는 24시간 봇이 아닙니다.

## 중요한 설정

| 설정 | 기능 |
|---|---|
| **댓글 기능 사용** | 다른 사람이 올린 최근 2시간 이내의 엔트리이야기 글에 예약 댓글 작성. **자기 글은 제외** |
| 댓글 문구 | 한 줄에 한 문구, 최대 50개 |
| 문구 선택 | 순서대로 순환 또는 직전 문구와 중복을 피하는 랜덤 |
| 댓글 간격 | 15분~24시간, 한 번에 다른 사람의 글 하나만 댓글 작성 |
| 최근 24시간 댓글 한도 | 1~6회 |
| **새 글 기능 사용** | 글 수 / 경과 시간 조건에 맞춰 초안 또는 실제 글 작성 |
| **조건 충족 시 새 글 자동 게시** | **별도로 체크해야** 공개 글이 실제로 게시됩니다. 기본값은 꺼짐 |
| 자동 게시 미체크 | 조건 충족 시 초안만 준비 (v2.0 사용자 기존 설정 유지) |
| 새 글 기준 | 내 최신 글 위 새 글 N개(최소 1개), 경과 N분(최소 1분), 또는 두 조건 모두 |
| 최근 24시간 새 글 한도 | 1~2회 |
| **조건 진단 / 미리보기** | 쓰기 요청 없이 조건 상태와 다음 문구 표시 |
| **자동 확인 시작 / 중지** | 브라우저가 열려 있을 때 분 단위 확인 |

**자동 게시 설정은 기존 설치에서 자동으로 켜지지 않습니다.** 이전 버전에서 초안 기능을 켰더라도, 공개 글 자동 작성을 원하는 경우에만 새 체크박스를 직접 켜야 합니다.

## 화면에 아무 반응이 없을 때

확장프로그램의 **조건 진단 / 미리보기** 버튼을 누르세요. 이제 실제로 무엇을 확인했는지 설명합니다.

- **댓글 기능 꺼짐** → '내 최신 글에 예약 댓글 사용'을 체크하세요.
- **댓글 문구가 비어 있음** → 댓글 문구를 줄 단위로 적으세요.
- **다음 댓글까지 NN분 남음** → 설정 간격이 지나지 않았습니다.
- **최근 24시간 댓글 한도 도달** → 시간이 지나거나 한도를 조정해야 합니다.
- **다른 사람의 최근 글 중 새 댓글 대상 없음** → 최근 2시간 이내 글 중 내가 아직 댓글 달지 않은 다른 사람의 글이 없거나, 그 작성자에게 최근 24시간 내 이미 댓글을 달았습니다.
- **내 최신 글을 찾지 못함** → **새 글 자동 작성**에 필요한 내 글을 찾지 못한 상태입니다. 다른 사람 글에 댓글 다는 기능과는 별개입니다.
- **새 글 기능 꺼짐** → '새 글 기능 사용'을 켜세요.
- **조건 부족** → 현재 새 글 수와 경과 시간이 설정한 기준에 미달합니다.
- **새 글 초안 준비됨** → 자동 게시 체크가 꺼져 있습니다.
- **새 글 자동 게시 성공** → 비공식 GraphQL API가 새 글의 ID를 반환했습니다.

**v2.2에서는 댓글 대상이 바뀌었습니다.** 내 글에는 댓글을 달지 않고 **최근 2시간 이내의 다른 사용자 글** 중 최신 글을 선택합니다. 같은 게시글에 중복 댓글을 달지 않으며, 같은 작성자에게는 최근 24시간 동안 최대 한 번만 댓글을 작성합니다. 전체 댓글 횟수는 설정한 24시간 한도를 따릅니다. 업데이트 후에는 새 동작을 확인한 다음 **자동 확인 시작**을 다시 눌러야 합니다. 자신의 최신 글을 찾는 계정별 검색은 오직 **새 글 작성 조건**을 판단할 때만 사용합니다.

### 주의사항

- 이전 시도 기록은 브라우저 로컬 저장소에 유지되므로, 업데이트했다고 댓글 간격이나 일일 한도가 초기화되지 않습니다.
- 미리보기를 눌렀을 때 실제 게시 요청은 절대 실행하지 않습니다. '자동 확인 시작' 후 설정이 맞아야 실행됩니다.
- 인증 실패, HTTP 401/403/429, CAPTCHA 및 도배 제한을 우회하지 않고 자동 실행을 중지합니다.
- 네트워크 오류로 실제 게시 성공 여부를 알 수 없을 경우 중복 게시를 막기 위해 같은 시도를 자동 재시도하지 않습니다.
- 비밀번호나 인증 토큰을 확장프로그램 설정에 저장하지 않습니다. 본인 계정 세션을 사용합니다.
- 실제 로그인 상태의 엔트리 사이트에서 최종 통합 검증을 하지는 못했습니다. 엔트리 비공식 API가 변경됐다면 조정이 필요할 수 있습니다.
